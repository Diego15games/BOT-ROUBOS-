# Controle de Roubos - Brasil Play Shox

Bot Discord.js para controle de roubos.

Comandos:

/painel-roubo -> Cria o painel
up nome_do_local -> Atualiza o local

Exemplos:

up navio
up ilha
up banco central
up loja 1

Recursos:

- Atualização automática
- Contagem regressiva
- Aviso quando liberar
- Salvamento em JSON
- Recuperação automática após reiniciar
- Hospedagem Railway
